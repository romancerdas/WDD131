Roman Cerdas

WDD 131

Overview

Purpose

The purpose of this website is to help Survivor fans track which seasons they have watched, browse basic season information, and choose what season to watch next.

Audience

The audience is Survivor fans, especially people who are watching the show for the first time or trying to keep track of many seasons.

Dynamic elements

JavaScript will be used to display Survivor season cards from an array of season objects. Users will be able to search seasons, filter by era or location, mark seasons as watched, and click a button to get a random season recommendation. The site will use event listeners, conditionals, objects, arrays, and array methods such as `filter()`, `forEach()`, and `find()`.

Pseudocode for your project

Create an array of Survivor season objects. Each object will store season number, title, location, era, winner, number of players, and watched status. When the page loads: Get the season card container from the HTML. Get the search input from the HTML. Get the filter dropdown from the HTML. Get the progress text from the HTML. Display all Survivor seasons on the page. To display seasons: Clear the season card container. Loop through the seasons array using forEach(). For each season: Create a card. Add the season title, number, location, era, winner, and players. Add a button that says "Mark Watched" or "Watched". Add the card to the page. When the user types in the search box: Get the search text. Use filter() to find seasons where the title, location, or winner matches the search. Display only the matching seasons. When the user chooses an era from the dropdown: Get the selected era. If the selected era is "all": Show all seasons. Otherwise: Use filter() to show only seasons from that era. When the user clicks a watched button: Find the selected season in the array. Change its watched value from false to true, or true to false. Update the season cards. Update the watched progress. To update progress: Use filter() to count seasons where watched is true. Display the number watched out of the total number of seasons. When the user clicks "Random Season": Use filter() to get seasons that are not watched. If there are unwatched seasons: Randomly select one season. Display it as the recommended season. Else: Show a message that all seasons have been watched.
